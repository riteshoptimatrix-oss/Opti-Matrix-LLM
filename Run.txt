========================================
  HOW TO RUN THE PROJECT
========================================

PREREQUISITES:
  - Node.js (v18+)
  - Python (v3.9+)

----------------------------------------
  BACKEND (FastAPI)
----------------------------------------

1. Open a terminal and navigate to the backend folder:

     cd backend

2. Create and activate a virtual environment (if not already done):

     python -m venv venv

     # Windows:
     venv\Scripts\activate

     # macOS/Linux:
     source venv/bin/activate

3. Install dependencies:

     pip install -r requirements.txt

4. Run the server:

     uvicorn main:app --reload --port 8000

   The backend will be available at: http://localhost:8000
   API docs will be available at:  http://localhost:8000/docs

----------------------------------------
  FRONTEND (Next.js)
----------------------------------------

1. Open a NEW terminal and navigate to the frontend folder:

     cd frontend

2. Install dependencies:

     npm install

3. Run the development server:

     npm run dev

   The frontend will be available at: http://localhost:3000

----------------------------------------
  TRAIN THE MODEL
----------------------------------------

1. Navigate to the backend folder:

     cd backend

2. Activate the virtual environment:

     # Windows:
     venv\Scripts\activate

     # macOS/Linux:
     source venv/bin/activate

3. Run the training script:

     python train.py

   - This reads all *_data.json files from the backend subfolders
   - Trains a TF-IDF + Logistic Regression pipeline
   - Saves the trained model to model.pkl

----------------------------------------
  TEST THE MODEL
----------------------------------------

1. With the virtual environment activated, run:

     python test_model.py

   - Loads model.pkl and runs sample queries
   - Prints predicted intent and confidence for each query

----------------------------------------
  NOTES
----------------------------------------

- Both servers should run during development (FastAPI on port 8000, Next.js on port 3000).
- The Next.js frontend calls its own server route (`/api/chat`), which proxies requests to the FastAPI backend (`/predict`).
- Model inference runs directly via `model.pkl`, and answers are deterministically mapped from `response_data.json` / `JSON_Data`.
- Out-of-domain/low-confidence queries automatically receive a safe company fallback message.
- To stop either server, press Ctrl+C in its respective terminal.
